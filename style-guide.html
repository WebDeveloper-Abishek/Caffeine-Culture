Arrow links

Keep both links inside arrows-pair so the first arrow points back. These examples navigate to pages, so they use anchors with accessible labels.

For a JavaScript carousel, use <button type="button"> with these same classes and labels instead of a link. A button performs an action; a link opens a destination.
